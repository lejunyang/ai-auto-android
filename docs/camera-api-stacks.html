为什么网上「能用」的说法很多
① 说的不是同一种模拟器
雷电 / 夜神 / MuMu / BlueStacks 自带虚拟摄像头功能，可直接选图片或视频文件当输入——那是它们自己实现的，与 AVD 无关。你要用的是官方 AVD。
② 那篇 CSDN 的标题本身就是「无法识别」
它给出的机制解释与我的实测一致：「模拟器未加载对应 DirectShow 或 Media Foundation 视频采集源」、「OBS 虚拟摄像头不暴露为传统 WDM/WDDM 视频捕获设备」。它是佐证，不是反证。
③ 但那篇有一处是编的
「Google 已在 Emulator 34.2.12+ 实验性支持 Virtual Camera via WebRTC Capture（通过 CDP 注入 MediaStream）」——我通读官方 release notes，无任何此类记载。WebRTC 在 emulator 里只用于容器音频串流与远程交互，与摄像头注入无关。
