模拟器扫码 · 宿主侧虚拟摄像头选型
三大系统方案对比
目标：宿主侧提供可编程虚拟摄像头，模拟器以 -camera-back webcam0 接入，实现不重启换码
结论：没有单一方案通吃三系统，但有统一的上层 API
驱动层三系统各不相同且无法统一；pyvirtualcam 在其上提供一致的 Python 接口，是唯一能让业务代码不分平台的一层。 Webcamoid 曾是跨平台候选，但 9.4.0（2026-07）已移除 macOS 虚拟摄像头，不再适合。

为什么 macOS 选择面这么窄
Apple 从 macOS 12.3 起用 CoreMediaIO Camera Extension 取代 DAL 插件， Sonoma 14.1 起非系统扩展的摄像头设备直接不可用。 系统扩展必须经 Apple 签名并公证 —— 这道门槛淘汰了几乎所有小型开源方案。 Webcamoid 9.4.0 移除 macOS 虚拟摄像头的官方理由正是"维护不善、在新系统上已无法正常工作"。
