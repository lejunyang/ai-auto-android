## 安全边界

- [ ] 辅助进程只监听 `localabstract`，无 TCP 监听
- [ ] 每个连接校验对端 uid，只接受 0 与 2000，有测试
- [ ] 方法集合类型化，无任意命令执行入口
- [ ] 消息、帧尺寸、显示数量都有上限且有超限测试
- [ ] 虚拟屏标志固定，不含显示安全内容的标志
- [ ] 凭据锁定时不唤醒、不解锁、不输入凭据；取帧返回锁定错误
- [ ] 目标显示无效或辅助进程不可用时不回退到主屏

## 功能

- [ ] 创建、列出、关闭虚拟屏
- [ ] 在虚拟屏上启动应用，主屏前台不变
- [ ] 对虚拟屏点按、滑动、按键、ASCII 文本
- [ ] 读取虚拟屏层级与帧
- [ ] `device.sleep` 使主屏息屏，与 `device.wake` 对称
- [ ] 不带 `--display` 时既有命令行为逐字不变（有测试）

## 模拟器证据（API 35）

- [ ] 记录 AVD、system image、分辨率与设备指纹
- [ ] 主屏息屏后虚拟屏点按、层级、取帧仍成立

- [ ] 测试 PIN 锁定后取帧返回锁定错误；测试 PIN 已清除
- [ ] 停止后无残留进程、虚拟屏、转发与临时文件
